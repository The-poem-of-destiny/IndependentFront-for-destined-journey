## 快速开始

| 平台        | 便携版（免装 Node）                                             | 从源码运行                                                        |
| ----------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| Windows x64 | 测试版未发布                                                    | ✅ 可用                                                           |
| macOS       | WIP（打包脚本 `scripts/build-portable.mjs` 仅支持 Windows x64） | WIP（`npm run dev` 会转发到 `dev.sh`，但尚未在真机 macOS 上跑过） |
| Linux       | WIP（同上）                                                     | WIP（同上，走 `dev.sh`，未经真机验证）                            |

### 方式一：Windows 便携版（测试版 · 尚未发布）

Windows 10 / 11（64 位）免安装压缩包：自带运行环境，**不需要安装 Node.js**。

1. 从 [Releases 页](../../releases) 下载 `narrative-engine-v<版本>-win-x64.zip`。
2. 把整个压缩包**完整解压**到一个文件夹（不要在压缩软件的预览窗口里直接运行）。
3. 双击解压出来的 `Start.bat`，浏览器会自动打开 `http://127.0.0.1:15173`。游玩期间保持那个命令行窗口开着。

存档保存在浏览器里、这个固定地址名下；升级时解压新版本再运行即可，存档自动保留。更多说明见包内的 `使用说明.txt`。
便携版暂不含背景音乐。

> ⚠️ 目前**还没有发布任何 Release**（打包流程已就绪，正在做发布前验证）。在此之前，请用方式二从源码运行。

### 方式二：从源码运行（Windows 可用）

**前置**：推荐 [Node.js](https://nodejs.org/) 22（`.nvmrc` 指定的 22.23.2 或更新的 22.x；24+ 亦可）+ npm 10.9.3。最低兼容范围以 `package.json` 的 `engines`（`^20.19.0 || ^22.13.0 || >=24.0.0`）为准；Node 20 已停止上游支持，不建议使用。

```bash
# 1. 下载源码
git clone https://github.com/The-poem-of-destiny/IndependentFront-for-destined-journey.git
cd IndependentFront-for-destined-journey

# 2. 按锁文件安装依赖
npm ci

# 3. 启动开发服务器
npm run dev
```

启动后浏览器自动打开 `http://localhost:5173`。

`npm run dev` 按平台转发到 `dev.bat`（Windows）或 `dev.sh`（macOS / Linux），两者都用 `--strictPort` 固定在 5173 端口启动，**不会结束任何已有进程**：端口被占用时直接报错退出，请先关掉占用它的程序（通常是上一次没关的开发服务器窗口）再重试。也可以直接运行启动器：Windows 双击 `dev.bat`，macOS / Linux 执行 `bash dev.sh`（后者尚未在真机上验证）。

## 首次游玩

启动后按下面三步走。设置页从首页进入。

### 1. 导入内容包（建议）

公开仓库只带**演示级占位内容**；完整的世界书、Agent 提示词、预设与目录通过**内容包**下发。没有内容包也能运行，并可以用演示内容创建角色。

**设置 → 内容包**，二选一：

- 点「**导入 / 升级内容包**」，选择本地的 `.json` 内容包文件；
- 或点「**登录 Discord**」，使用符合目标社区资格的账号登录，再点「**检查更新**」，发现新版本后点出现的「**更新到 <版本>**」完成安装。

在线获取需要部署者配置独立内容中心服；本地 BFF 使用 `POEM_PACK_SERVER_URL`，静态部署构建时使用 `VITE_PACK_SERVER_URL`，均填 HTTPS origin（本机回环测试允许 HTTP）。详见[客户端配置与授权说明](docs/reference/discord-content-pack-client.md)。

授权有效期内可以离线使用，联网时自动复验并续期。退出、账号不匹配、到期或明确撤权后回落到占位内容。授权包的世界书与预设编辑仅在当前会话保留，不进入备份；显式本地 JSON 导入仍支持离线使用。旧版本未标记来源的明文包会清理并锁定，需要重新登录获取，玩家自建与工坊内容保留。

### 2. 添加 API（必须，只需一个）

**设置 → API 配置 →「+ 添加 API」**：

- 用途选「**文字 LLM**」，按服务商的真实接口选「**协议**」；
- 填「**主链接**」与「**API Key**」；
- 「**模型**」可点「**获取模型**」从列表选，也可以手动填写模型 id；
- 保存前点「**测试连接**」确认通过。

支持 OpenAI 兼容接口以及 Gemini、Claude 原生协议。选什么模型可参考 API 配置页下方的「**模型推荐**」卡片。

所有 Agent 默认跟随第一个文字 LLM 源，**不必逐个绑定**（直出模式建档时会把当时的第一个源固定到本存档）；只想给某个 Agent 换模型时，再到「Agent 配置」里单独指定。

以下都是可选项：

- **记忆召回**：默认是「LLM 召回（兼容模式）」，不需要额外配置。想用「Embedding 向量召回」时，先在 API 配置里添加一个用途为「向量嵌入 (Embedding)」的源，再到 **设置 → 记忆 & 缓存** 切换召回模式，并在「Embedding 源」里选中它。
- **Reranker**（候选重排）与**图像生成**同样不是必需的。

### 3. 新建存档

回到首页点「**新建存档**」，进入准入页「**启程前的准备**」：

1. **选择生成模式**：「Agent 模式」/「直出（无缓存优化）」/「直出（缓存优化）」。模式随存档固定，创建后不可更改。
2. **本机配置检查**：标「需要处理」的项目会阻止开始，标「可选」的不会；与 API、Agent 相关的项旁边有跳转到对应设置的按钮。这一步只检查本机配置，不发送模型请求。
3. 点「**开始创建角色**」（未装内容包时按钮显示为「使用演示内容创建角色」），按八步创建向导（难度选择 → … → 确认提交）完成角色、背景与剧情规划，即可进入游戏。

> 打字即游玩——在输入栏写出你的行动，AI 和引擎会一起回应。没有选项按钮限制你。

可选：想调整正文提示词时，到 **设置 → Agent 配置** 选对应 Agent，在「预设」里切换或修改；内容包自带的预设是只读的，修改时会自动复制一份「我的修改」再改。

## 特性

- 🎭 **多 Agent 协作引擎**——10+ 个专职 Agent（叙事/记忆/剧情/战斗/制作/角色生成…）按 DAG 编排，各司其职
- ⚔️ **完整游戏系统**——T1→T7 力量层级、7 级品质、23 血脉、10 势力；战斗（8 步伤害管线）/ 制作（DC+骰检）/ 集群 / 士气 / 好感度
- 🌍 **开放世界剧情**——大事件 + NPC 议程去中心化演化；主角自由介入，粉碎一条议程线会涌现新的权力真空与势力博弈
- 🎨 **叙事优先 UI**——Vue 3 前端，10 主题，叙事正文是视觉主角，面板退后服务
- 🗺️ **地图系统**——真实地块 / 混合通行图寻路 / 路线与天数预览 / 天气，位置在叙事里说得通也走得通
- 🎲 **随机事件**——引擎按概率逐天掷骰产出候选事件，AI 在叙事方便的时机自然演绎，不打断节奏
- 🖼️ **情景插画**——NovelAI 云端或 ComfyUI 本地出图，插画就地嵌进正文，出过的图进 CG 图鉴
- 🛠️ **创意工坊**（入口暂时锁定）——浏览 / 安装 / 更新社区世界书与内容包，支持点赞订阅；因数据结构不兼容，入口目前临时关闭
- 🔌 **SillyTavern 兼容**——支持世界书 / 预设格式，可导入既有生态资源（角色卡导入尚未实现）
- 💾 **本地存档 & 互传**——IndexedDB 本地存储，存档在你自己的机器上；单存档可导出导入，换机迁移不丢进度

## 技术栈

- **引擎**：TypeScript（`src/core/`，160+ 模块）
- **前端**：Vue 3 + Pinia + Vite（`src/ui/`）
- **存储**：IndexedDB（Dexie）
- **AI**：OpenAI 兼容 API + function calling
