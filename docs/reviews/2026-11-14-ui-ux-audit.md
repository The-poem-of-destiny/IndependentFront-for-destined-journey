## 一、全局壳层与共享组件

### 1.1 导航与页面壳

- **G-01 · P2 · 从「扩展管理」返回设置页，永远落回「API 配置」** 🖥 — 在任意设置分区点左栏「扩展管理」再点「← 返回」，原来看的分区、Agent 选择、滚动位置全部丢失。证据：`SettingsPage.vue:57`、`ui-store.ts:122-127`。方向：在 ui-store 里记住上次的设置分区，返回时恢复。
- **G-02 · P2 · 设置页切换分区不复位滚动条** 🖥 — 在「Agent 配置」滚到底后点「世界书」，新分区直接显示在 975px 处；从世界书列表点「浏览」进条目编辑器同样停在半中间（实测 `settings-content.scrollTop` 分别为 974 与 513）。玩家看到的是一页没头没尾的内容。方向：切分区、切子视图时把滚动容器归零。
- **G-03 · P1 · RPM 等待弹窗上的「打开 API 限制设置」会悄悄杀掉正在等待的那一回合** — 回合进行中请求排队，点这个按钮会导航去设置页，游戏页随之卸载、管线中止、在飞的插画请求也被中止（照样计费），全程没有任何提示。证据：`ApiRateLimitWaitPopup.vue:26-28,86-88`、`GamePage.vue:352-397`。方向：不离开游戏页打开限流设置（弹窗），或至少先警告「本回合会被取消」。 📌 2026-11-14 已修（PR #151，未真机）：点按钮先过离开游戏页确认（`lib/leave-game-guard.ts`）；「不离开游戏页打开限流设置」未做。
- **G-04 · P3 · 内容态横幅无法关闭** 🖥 — 占位态下「未导入内容包，当前为演示级占位内容」在首页与设置页常驻，设置页里还固定占掉顶部一行。证据：`ContentStatusBanner.vue:53-59,169-200`。方向：允许按会话关闭。
- **G-05 · P2 · 横幅「导入内容包」遇到冲突会把刚选的文件丢掉** — 弹原生确认框让人「前往 设置 → 数据与备份 → 导入内容包 完成确认」，点确定跳去设置页但文件要重选，点取消则什么都不发生。证据：`ContentStatusBanner.vue:97-137`。方向：原地打开安装确认弹窗并沿用已解析的计划。

### 1.2 提示（Toast）与确认

- **G-06 · P1 · 重要错误只以 3 秒 toast 出现** — 启动期两条会让远端调用停摆的错误（「API 密钥无法迁移到安全存储…」「API 配置迁移失败；远端调用已暂停…」）只闪 3 秒就再也看不到；全 UI 92 处错误 toast 里只有 1 处给了更长时长。证据：`App.vue:28-35`、`ui-store.ts:161-166`、`game-pipeline.ts:1178`。方向：错误类 toast 改为常驻或显式关闭；阻断性状态进持久横幅。 📌 2026-11-14 已修（PR #151，未真机）：错误 toast 默认 8 秒、警告 5 秒，`duration: 0` 常驻；启动期两条 API 迁移错误改为常驻。持久横幅未做。
- **G-07 · P2 · 确认方式全应用四套并存** — ① 原生 `confirm/alert/prompt`（存档删除、世界书新建/删除/重置、条目删除、日历删除、图鉴删除、角色删除、物品丢弃、记忆删除、人设编辑、快照恢复、捏人预设等约 20 处）；② 应用内弹窗确认；③ 行内「再点一次」；④ 不可逆操作完全不确认。原生框不跟主题、无法标危险色，代码注释自己也写着在嵌入式 webview 里会直接返回 false。证据：`SaveManager.vue:168`、`WorldBookSection.vue:58,113,136,157`、`WorldBookEditor.vue:446`、`CalendarPanel.vue:189`、`CgGalleryPanel.vue:252`、`SceneImageSegment.vue:344`、`CharacterListPanel.vue:109`、`ItemsPanel.vue:102,119`、`MemoryPanel.vue:120`、`PlayerPersonaEditorModal.vue:72`、`SnapshotPanel.vue:78`、`PresetModal.vue:79,127`、`DataSection.vue:298`。方向：做一个带危险变体的共享确认组件，全部换过去。
- **G-08 · P3 · Toast 没有关闭按钮、点击会静默复制、数量不封顶** — 点错误/警告 toast 会把文字复制进剪贴板但没有任何反馈；悬停不暂停；可以无限堆叠。证据：`ToastContainer.vue:13-39`、`ui-store.ts:161-171`。 📌 2026-11-14 已修（PR #151，未真机）：加了关闭按钮、悬停暂停，错误/警告点击复制后原地显示「已复制」。数量仍不封顶。
- **G-09 · P3 · 首次启动弹出「远程素材同步：新增 11 · 更新 0 · 删除 0 · 跳过 0 · 失败 0」** 🖥 — 新玩家第一眼看到的提示是一行后台同步统计，而且压在内容横幅上。方向：成功且无失败时不提示，或只说「已下载 11 张角色立绘」。

### 1.3 弹窗基础件

- **G-10 · P2 · 面板一关，里面的状态全没** — `AppModal` 的内容是 `v-if`，所以每次关闭再打开：背包回到默认页签与未选中、剧情回到时间线且剧透状态复位、记忆的搜索/筛选/分页清空、任务筛选复位、图鉴选中格丢失（「跳回那条消息」会关弹窗，回来永远是未选中的网格）、地图回到「标记地图」页签且路线规划清空。证据：`AppModal.vue:66`、`PlotPanel.vue:25`、`ItemsPanel.vue:16-18`、`MemoryPanel.vue:16-23`、`CgGalleryPanel.vue:45-46`、`MapPanel.vue:152`。方向：把各面板的视图状态放进 store，或对这些弹窗用 `v-show`/KeepAlive。
- **G-11 · P2 · 表单弹窗点遮罩或按 Esc 直接丢稿** — 添加/编辑 API（地址、密钥、JSON 覆盖、请求头）、美化规则编辑、世界书条目编辑、日历条目草稿都没有脏检查。证据：`AppModal.vue:40-41`、`ApiSection.vue:672-677`、`RuleEditorModal.vue:70-75`、`WorldBookEditor.vue:156-161,441-443`、`CalendarPanel.vue:166`。方向：给 `AppModal` 加脏检查钩子，表单有改动时先确认。
- **G-12 · P2 · 弹窗没有窄屏版式** — `AppModal` 在任何宽度都是 24px 内边距，没有一条媒体查询；按钮文字不换行。工坊详情页脚一行塞 6 个按钮。证据：`AppModal.vue:195-206`、`AppButton.vue:49`、`WorkshopDetailModal.vue:491-529`。
- **G-13 · P3 · 点击区偏小或只在悬停时出现** — 弹窗关闭 × 为 28×28；存档行的操作按钮 28px 且宽屏下只在悬停/聚焦时显示（触屏平板永远看不到）；工坊卡片 ♥/★ 为 26px。证据：`AppModal.vue:175-178`、`SaveManager.vue:791-807,1030-1032`、`WorkshopSocialActions.vue:129-130`。
- **G-14 · P3 · `AppTabs` 没有页签语义，溢出时无提示** — 没有 `role=tablist/tab`、没有方向键；滚动条被隐藏，窄屏放不下的页签直接看不见（角色查看器 7 个页签时「相册」可能被藏）。证据：`AppTabs.vue:28-57`。

- **G-22 · P3 · 重命名时按 Esc 关掉整个存档窗口** — 草稿名丢失；输入框也没有自动获得焦点，要再点一下。证据：`SaveManager.vue:528-548`、`modal-focus.ts:46-49`。

- **H-01 · P2 · 「退出」在普通浏览器标签页里点了没反应** 🖥 ✔ — 它只调 `window.close()`，浏览器会忽略用户自己打开的标签页，没有任何提示。证据：`HomePage.vue:111-113`。方向：非独立壳环境下隐藏，或点击时说明。
- **H-02 · P1 · 一级按钮「扩展管理」通向一个三块全是「暂未开放」的页面** 🖥 — 首页四个主按钮之一、设置页左栏、游戏菜单「扩展」都指向这里；页面上「原版扩展 规划中 / 暂未开放」「创意工坊暂未开放」「尚无可配置的存档」，没有任何一件事能做。空态文案还引导人去上面那张锁着的卡（见 W-02）。`UIL-04` 仍未处理。证据：`HomePage.vue:62,264-272`、`GameMenu.vue:43-47`、`ExtensionManagementPage.vue:42-87`。方向：没有可操作内容时把入口降级或隐藏。 📌 2026-11-14 已修（PR #151，未真机）：首页「扩展管理」只在工坊解锁或已装社区扩展时显示（`workshop-lock.ts` 的 `hasExtensionWork`）；设置页左栏与游戏菜单的入口保留。
- **H-03 · P2 · 「继续」不说会进哪个存档** — 直接进入最近更新的那个，按钮上没有存档名、时间或回合数，多存档时容易进错。证据：`HomePage.vue:130-137,233-241`、`latest-save.ts:9-22`。方向：加一行副标题「存档名 · 时间」。
- **H-04 · P2 · 没有「重新开始」：放弃的角色草稿一直留着** — 点「新建存档」会回到上次没做完的角色，甚至直接停在第 8 步；只有创建成功或刷新页面才清空。证据：`CreatePage.vue:88-91`、`HomePage.vue:106-109`。方向：入口处给「继续上次草稿 / 重新开始」。 📌 2026-11-14 已修（PR #151，未真机）：创建页脚加「重新开始」。

- **H-07 · P3 · 首页减动效与对比度的漏网项** — 「新建存档」按钮没进减动效规则；版本页脚是 0.4 不透明度的弱化字；「存 档 管 理」这类字间空格会被读屏器逐字读。证据：`HomePage.vue:680-700,760-779,832-860`。

## 三、创建角色（8 步向导）

### 3.1 准入页（配置检查 + 生成模式）

- **C-00 · P2 · 准入页的措辞对新玩家太硬** 🖥 — 第一次建角色就要在「Agent 模式 / 直出（无缓存优化）/ 直出（缓存优化）」里三选一且「创建后不可更改」，解释用的是「按请求次数计费的渠道」「按 Token 计费且支持缓存的渠道」「整楼可能不止一次请求」；没有推荐项。主按钮在本地内容态下叫「使用演示内容创建角色」，内容横幅又被嵌在页面中间。方向：给一个带「推荐」的默认选项，把计费细节收进展开说明。
- **C-01 · P2 · 没选生成模式时「开始创建角色」置灰，却不说原因** 🖥 — 问题清单不提生成模式，甚至会在一个点不动的按钮旁边显示「对话配置已齐备。」。证据：`CreatePage.vue:34-41,197-214`。
- **C-02 · P2 · 检查项直接显示内部 Agent id，「配置 Agent」落不到出问题的那个** — 文案如「story：需要选择对话 API。」「plot_pre_check 绑定的 API 已不存在」「direct_cached：尚未选择模型。」；按钮打开设置页后停在上次选中的 Agent，N 条问题给 N 个一模一样的按钮。证据：`journey-readiness.ts:26,50,75`、`CreatePage.vue:198-202`、`SettingsPage.vue:84-92`。方向：换成中文名，跳转请求带上 agentId。
- **C-03 · P2 · 缺内容包时没有去处** — 「没有可用的角色内容目录，请先导入内容包。」旁边只有 API 设置按钮，而导入入口埋在「设置 → 数据与备份」最底下。`UIL-08` 部分仍在。证据：`CreatePage.vue:194-196,211-219`。

入口都在左侧工具栏：点图标 → `game.showModal(id)` → 一个页面级弹窗。每个弹窗关闭即卸载（见 G-10）。

### 6.1 地图

结构：弹窗「地图」→ 页签「标记地图」（默认）/「势力地图」。标记地图里再开「标记工作台」侧抽屉，抽屉里又有「标记列表 / 编辑」两个子页签。

- **MAP-01 · P1 · 标记编辑会把别的标记的值（或空值）写进当前标记** ✔ — 在地图上点标记 B（或新放一个标记）再打开工作台点「编辑」改颜色，B 的名称/分组/描述被替换成上一个编辑过的标记 A 的内容（或空串），1 秒内落库。原因是表单只在从工作台列表选中时才填充，而地图点击与新增直接改了选中项。证据：`useMapMarkers.ts:196,254-262`、`MapPanel.vue:331-375,688-694`。方向：改为监听选中 id 来填表单。 📌 2026-11-14 已修（PR #151，未真机）：表单改为监听选中 id 填充（`composables/useMarkerDraft.ts`）。
- **MAP-02 · P1 · 「设为当前位置」一键改写玩家位置，不确认、成功也没提示** — 它是信息卡操作行的第一个按钮，样式与「查看路线」一模一样；点错后存档位置已提交，下一回合 AI 就从新位置写起，唯一的撤销是回退快照。证据：`MapPoliticalTab.vue:902-913,1408`、`game-store.ts:1681-1684`。方向：确认框写出「旧地点 → 新地点」或给撤销 toast，并与路线类按钮视觉分开。 📌 2026-11-14 已修（PR #151，未真机）：确认框写出「旧地点 → 新地点」，成功后提示。
- **MAP-03 · P1 · 势力地图不能按名字找地方，地块也只能用鼠标选** — 想查去正文里提到的某座城的路线，只能在画布上平移缩放用眼睛找（名字标签过了缩放阈值才出现）；没有搜索框，也没有键盘选择。从打开到「去 X 有多远」是 4 次点击加一次目视搜索。证据：`MapPoliticalTab.vue:831-843,1124-1133`。方向：加地名搜索，选中并框住地块。 📌 2026-11-14 已修（PR #151，未真机）：势力地图加地名搜索（地块 / 中层 / 势力名子串匹配，`lib/map-place-search.ts`），选中并框住地块。
- **MAP-04 · P2 · 「出发」会悄悄替换输入框里已经写了一半的行动**。证据：`MapPoliticalTab.vue:884-890`、`InputBar.vue:21-29`。方向：追加，或输入非空时先问。
- **MAP-05 · P2 · 地图每次打开都回到用处较小的「标记地图」页签，路线规划关窗即丢** — 途经点、避开点、缩放、着色档都是组件本地状态。证据：`MapPanel.vue:152`、`MapPoliticalTab.vue:165,170`。
- **MAP-06 · P2 · 标记信息卡是死胡同，改个名字要钻三层** — 点标记弹出的卡片没有「编辑」也没有关闭；要改名得开工作台 → 在列表里找到它 → 切到「编辑」。新放的标记被默默命名为「新标记」，编辑器不会自动打开。证据：`MapPanel.vue:535-541,582-649,679-695`、`useMapMarkers.ts:186-199`。
- **MAP-07 · P2 · 「删除标记」立即且永久，内容包自带的预设标记删了没法恢复**。证据：`MapPanel.vue:797-805`。
- **MAP-08 · P2 · 标记的修改在失焦时悄悄保存，没有保存按钮也没有「已保存」** — 改名字时地图上的标签要等输入框失焦才变；落库失败只进控制台。证据：`MapPanel.vue:295-305,730-757`。
- **MAP-09 · P2 · 地图标记能拿到键盘焦点，但回车/空格没反应**。证据：`useMapMarkers.ts:228-229,252-262`。
- **MAP-10 · P2 · 窄屏下标记工作台不堆叠** — 固定 260px 一列。证据：`MapPanel.vue:1059-1060,1452`。
- **MAP-11 · P2 · 给玩家看的开发词与文件名** — 着色档按钮「中层」；浮层「未识别像素 x% · 撞色地块 n —— 地图图形与数据可能不是同一版」；「地图图形数据未安装（缺少 provinces.png）」；原始错误信息直接拼进「势力地图构建失败：…」。证据：`MapPoliticalTab.vue:84-88,536-543,1225`、`useMapPolitical.ts:125,158`、`useMapViewer.ts:144,242`。
- **MAP-13 · P2 · 标记地图默认缩放下，168 个标记名牌全部叠在一起** 🖥 — 打开地图第一眼是一片互相遮挡的黑底名牌，底图和大部分名字都看不清；工具栏只有「高清地图 / 超清地图 / 新增标记 / 标记工作台」，没有按分组筛选、没有「只看当前位置附近」、也没有按缩放级别收起名牌。方向：名牌按缩放分级显示（先国家、再省、再城镇），并提供分组筛选。
- **MAP-14 · P2 · 势力地图默认视图只有色块，没有任何名字或图例** 🖥 — 「自动·势力」档下整张图是十来块颜色，要放大过阈值或逐块点开才知道哪块是哪国。测试存档里左上角还显示「位置未定位」而「定位玩家」置灰，没有说明怎样才算定位上。方向：势力档直接标势力名，或给一个颜色图例。
- **MAP-12 · P3 · 零散项** — 两个页签对「玩家在哪」的判定可能不一致（标记页签用双向子串模糊匹配，势力页签用引擎解析）；NPC 位置标签是不可聚焦的 span，点了只平移不高亮；工作台列表里的「定位」嵌在行按钮内，键盘到不了；没有地图源时把正常的「无内容」画成报错，而「新增标记」「标记工作台」仍可点；编辑器不能改图片但卡片支持图片轮播；弹窗里又套了一个「地图」标题；信息卡的 × 没有尺寸；「设为途经点 / 避开此地」在还没有路线时就可点，效果要点了「查看路线」才看得到。证据：`MapPanel.vue:93-117,175,510-511,527-541,558-567,664-669,701-717`、`MapPoliticalTab.vue:1232,1410-1415`。

### 6.2 角色

结构：同一个 NPC 有**两个互不相通的界面** —— A）工具栏「角色」→ 弹窗「角色列表」（概览/状态/装备/技能/登神/背包，可删除、可重铸）；B）场景栏「在场」那一行 → 通栏「角色查看器」（档案/编年史/状态/装备/技能/背包/相册，只读）。

- **CHR-01 · P1 · 不在场的 NPC 看不了编年史、相册和完整档案** — 查看器唯一的入口是场景栏「在场」的行；角色列表弹窗里没有任何办法打开它。想看一位不在身边的同伴的经历，无路可走。证据：`ScenePanel.vue:67-75,342,442`、`CharacterListPanel.vue:326-345`。方向：列表行加「查看档案 / 编年史」，或把两个界面合并。 📌 2026-11-14 已修（PR #151，未真机）：角色列表可打开 `CharacterViewerModal`。两套界面未合并（CHR-03 仍在）。
- **CHR-02 · P1 · 角色列表的 NPC 行键盘到不了** — 是带 `@click` 的 div，键盘用户永远只能看到第一个 NPC；状态效果行同样。证据：`CharacterListPanel.vue:237-246,493-498`。 📌 2026-11-14 已修（PR #151，未真机）：NPC 列表改为 listbox + roving tabindex。
- **CHR-03 · P2 · 两个 NPC 详情显示的字段和能做的事各不相同** — 所在地/年龄/性别只在列表里；当前目标/别名/喜爱只在查看器里；删除与重铸只在列表，编年史与相册只在查看器。玩家无从预判什么在哪。证据：`CharacterListPanel.vue:300-307,389-408,546`、`character-viewer.ts:127-136`、`CharacterViewerModal.vue:80-88`。方向：一份标准的 NPC 档案，列表行直接打开它。
- **CHR-04 · P2 · 「重铸」不说明它是一次付费的 AI 调用，且会不可逆地替换这个条目** — 唯一的文字是占位符「可选：哪里不对…」。背包面板的重铸同样（见 ITM-03）。证据：`CharacterListPanel.vue:204-222,546-562`。
- **CHR-05 · P2 · 游戏内没有办法给 NPC 设画像，也没有提示去哪设** — 查看器左栏只有一个巨大的首字。证据：`CharacterViewerModal.vue:224-234`、`StatusOverview.vue:699`。
- **CHR-06 · P2 · 角色列表窄屏下不堆叠** — 列表固定 18rem，文件里没有任何媒体查询，约 390px 时详情栏只剩 60px 左右。证据：`CharacterListPanel.vue:711-713`。
- **CHR-07 · P3 · 零散项** — NPC 数量一变（新角色登场、删除）选中项就跳回第一个；列表用手写页签而查看器用 `AppTabs`；两处好感度条画法不同（一个从左填、0 在 50%，一个从中间零点向两边长）；玩家的「命运点数」顶在 NPC 列表上方；编年史显示原始「重要度 N」、排序按钮显示的是当前状态而不是动作、脚注写「叙事会在预算内读取…」。证据：`CharacterListPanel.vue:47-52,76-79,228-231,264-268,326-345`、`CharacterViewerModal.vue:281-288`、`CharacterChronicleTab.vue:104-106,141,172-174`。 📌 2026-11-14 部分已修（PR #151，未真机）：选中项按名字保持，NPC 数量变化不再跳回第一个；其余零散项未做。
- **CHR-08 · P3 · 玩家画像的入口看不出来** — 只有 title 提示；没有大画像时，好奇点一下自己的头像会直接弹出系统文件选择框。画像设置弹窗边调边存、没有「取消」，「复位」回到的是默认取景而不是打开前的取景。证据：`StatusOverview.vue:357-368`、`PortraitSettingsDialog.vue:111-127,212-216`。

### 6.3 日历

- **CAL-01 · P2 · 「保存」置灰却不说原因** — 标题为空或日/月越界时按钮不可点，哪一格有问题没有提示。证据：`CalendarPanel.vue:429-436`、`calendar-panel.ts:127-136`。
- **CAL-02 · P2 · 开着「显示选择」或编辑器时点日期，什么都不出现** — 右栏是三选一（编辑器 / 显示选择 / 当日详情），格子会高亮但当日详情出不来。证据：`CalendarPanel.vue:313,348,442,516`。
- **CAL-03 · P2 · 「不再显示」立刻隐藏一个节庆或生日，没有撤销；要恢复得找到「显示选择」，而沉浸模式下那个入口根本不渲染**。证据：`CalendarPanel.vue:251-260,572-580`。
- **CAL-04 · P3 · 零散项** — 「每年重复」默认开着，而占位示例「约定之日」是一次性的；「普通 / 沉浸」的含义要切换之后才解释；「日期未定」的行不能点也不能就地隐藏。证据：`calendar-panel.ts:99`、`CalendarPanel.vue:229-278,331-342,605-615`。

### 6.4 任务

- **QST-01 · P1 · 任务列表会自己变空，而且看不到复位筛选的办法** ✔ — 状态只有「进行中 / 已完成」两种时，选中「进行中」再把最后一个进行中的任务标记完成：状态只剩一种，筛选条（`length > 2` 才显示）消失，但筛选值仍停在「进行中」，列表显示「暂无符合条件的任务」，看起来像任务全被删了，直到关掉重开。证据：`QuestsPanel.vue:57-63,159,223`。 📌 2026-11-14 已修（PR #151，未真机）：当前筛选值不在可选项里时回到「全部」。
- **QST-02 · P2 · 任务详情浮层吃不到 Esc，键盘也进不去** — 它是弹窗外的裸 Teleport：按 Esc 关掉的是整个任务弹窗；焦点被拉回父弹窗，Tab 永远到不了「标记完成 / 删除」。证据：`QuestsPanel.vue:226-294`、`modal-focus.ts:44-49,66-68`。方向：改用可嵌套的 `AppModal`。
- **QST-03 · P2 · 删除任务不确认，写库失败也没提示** — 界面先改了，失败只进控制台，重载后悄悄变回去；「焦点」下拉同样。证据：`QuestsPanel.vue:25-34,93-119,209-218,287-289`。 📌 2026-11-14 已修（PR #151，未真机）：写库失败回滚并提示。
- **QST-04 · P2 · 失败的任务挂着「标记完成」，还删不掉** — 「已完成」区里也放失败任务，按钮条件却只看「不是已完成」，点了就把失败改成成功。证据：`QuestsPanel.vue:66-69,209-218,280-289`。 📌 2026-11-14 已修（PR #151，未真机）：已完成 / 失败的任务不再给「标记完成」，改给「删除」。
- **QST-05 · P2 · 任务卡片是 div 不是按钮** — 键盘打不开任务。背包条目行同样（`ItemsPanel.vue:256-262`）。证据：`QuestsPanel.vue:179-184`。
- **QST-06 · P3 · 文案** — 「焦点」只说「追踪其进展」不解释作用；空态不说任务从哪来；详情里状态重复两遍、用了「关注度」这个词；焦点下拉没有标签。证据：`QuestsPanel.vue:139-143,223,237-256`。

### 6.5 背包

- **ITM-01 · P2 · 背包里没有装备/使用按钮，也不解释为什么** — 「装备」页签只是筛选；没有穿戴/卸下/使用，也没有一句「在输入框里写出行动即可」。找「使用」的玩家走进死胡同。证据：`ItemsPanel.vue:25-27,276-297`。方向：加一行说明，或给一个「使用」按钮把行动填进输入框。
- **ITM-02 · P2 · 「丢弃」会丢掉整叠，确认框却不写数量** — 可能是全部 20 瓶药水；不能只丢一部分。证据：`ItemsPanel.vue:96-105`。
- **ITM-03 · P2 · 「重铸」看起来像游戏里的锻造，其实是让 AI 重写这条数据** — 它和「丢弃」并排；提示用的是机制语言（「应该 400 能量伤害却只有 200 物理伤害」），不提费用，也不提会替换原条目。证据：`ItemsPanel.vue:294-313`。方向：改名「让 AI 修正此条目」，注明费用与替换，考虑收进「…」菜单。
- **ITM-04 · P2 · 窄屏崩版** — 列表固定 18rem 与详情并排，没有媒体查询。证据：`ItemsPanel.vue:441-450`。
- **ITM-05 · P3 · 「技能」页签的空态写「暂无物品」「选择一件物品查看详情」**。证据：`ItemsPanel.vue:255,315`。
- **ITM-06 · P2 · 「装备」既是页签又是筛选项** 🖥 — 顶部页签是「背包 5 / 装备 3 / 技能 2」，「背包」页签下面又有一排筛选「全部 / 装备 / 消耗品 / 材料」。背包页签里列着已穿在身上的精钢长剑，条目上却看不出它是否已装备；两个「装备」各指什么（身上穿的 / 物品类别）没有说明。方向：页签改叫「已装备」，并在背包条目上标出「已装备」。

### 6.6 剧情

- **PLT-01 · P1 · 防剧透有漏洞：章节标题与章节摘要从不打码** — 列表视图里每一章（包括未到的章节）的标题、摘要和总纲摘要都直接显示，只有事件会变成「？？？」；时间线上的章节条也不做可见性检查。证据：`PlotPanel.vue:166-219`、`plot-timeline.ts:243-251,302-317`。方向：未揭示章节与事件同样打码，或明说「章节名不算剧透」。 📌 2026-11-14 已修（PR #151，未真机）：未到达章节的标题与摘要打码（`plot-thread-view.ts` 的 `isChapterMasked`）。📌 2026-11-14 更正：本条说「总纲摘要」也应打码，不成立 —— `PlotOutline.summary` 在 `src/core/types/types.ts` 里声明为防剧透层下的可见部分，修复刻意保留它可见。
- **PLT-02 · P2 · 三个各管各的「剧透模式」开关，而且打开一个什么都不会揭示** — 剧情面板、事件线面板、时间线各有一个，列表视图里同时出现两个；切视图就丢。开关打开后每个「？？？」仍要逐个点，这一点只写在悬停提示里。证据：`PlotPanel.vue:32,169-183`、`PlotThreadsPanel.vue:14,78-90`、`PlotTimeline.vue:31,194-206`。方向：合成一个，改名如「允许逐条揭示」并把说明写在明面上。
- **PLT-03 · P2 · 时间线节点文字被截断，全文只在悬停提示里** — 触屏与键盘看不到；已揭示的节点点不了，涉及/埋向/回收/动机这些细节只在「列表」视图有。证据：`PlotTimeline.vue:280-295,569-584`。
- **PLT-04 · P2 · 没有大纲时「列表」视图把事件藏了** — 支线模式或只有事件没有大纲时，列表只剩一句模式说明，而时间线里明明有这些事件。证据：`PlotPanel.vue:22,127-131,160-164,257`。
- **PLT-05 · P3 · 设计术语** — 「主线明线（事件线）」「埋向 / 回收」「伏笔连线」「世界线已变动×N」「px/天」。证据：`PlotThreadsPanel.vue:74,145-148,168`、`PlotPanel.vue:187-189`、`PlotTimeline.vue:182`。

### 6.7 记忆

- **MEM-01 · P2 · 给玩家显示内部记忆 id** — 卡片首行、详情页脚「ID: …」、删除确认「删除记忆「<id>」？」都是 id；关联角色找不到名字时也回退成原始 id。证据：`MemoryPanel.vue:77-79,120,168,205,212`。方向：换成内容摘录或时间。
- **MEM-02 · P2 · 删除与复制失败不提示，复制成功也没反馈**。证据：`MemoryPanel.vue:108-132`。
- **MEM-03 · P2 · 新模式的记忆面板满是引擎术语，还有一句没有出口的提示** — 「旧摘要来源指纹缺失或原文已修订，无法验证，需重新补建；本轮上下文以原文代替。」但界面上没有任何「补建」控件。两套记忆界面由一个看不见的存档标记决定，没有地方告诉玩家为什么不一样。证据：`StoryMemoryV2Panel.vue:218,230-232,261-266`、`MemoryPanel.vue:13,137`。
- **MEM-04 · P3 · 重要度的筛选档与颜色档对不上** — 筛选是「≥7 / 4-6 / ≤3」，颜色是「≥8 高、≥5 中」，★7 的记忆过了「≥7」却是中档色。证据：`MemoryPanel.vue:30-33,90-94,194-196`。

### 6.8 图鉴

- **CG-01 · P1 · 付费重画一点就发，而且在图鉴里看不到它的去向** — 「重画 / 保存并重画 / 重画一张」单击即排队，没有确认、没有费用行；唯一反馈是 toast「已排进生成队列」。图鉴只列已完成的图，排队中、生成中、失败的都不显示，要回到正文才知道结果。证据：`CgGalleryDetail.vue:226,306-313,322`、`CgGalleryPanel.vue:191-208`、`cg-gallery.ts:55-56`。 📌 2026-11-14 已修（PR #151，未真机）：重画先确认并注明可能产生费用；图鉴详情里显示同一锚点下排队中 / 生成中 / 失败的那几张。
- **CG-02 · P2 · 从图鉴重画遇到限额是死胡同** — 正文里的手动路径会给「仍然生成」的确认，图鉴直接调生成且不带确认标记，只得到一条警告 toast。同一个动作两种行为。证据：`CgGalleryPanel.vue:191-207`、`useManualSceneImage.ts:65-96`。 📌 2026-11-14 已修（PR #151，未真机）：图鉴重画改走正文同一条手动路径（`useManualSceneImage`），超限同样给确认。
- **CG-03 · P2 · 编辑标题/说明时按 Esc 会关掉整个图鉴** — 输入框想用 Esc 取消编辑，但弹窗的捕获监听先一步把图鉴关了。证据：`CgGalleryDetail.vue:184,205`、`modal-focus.ts:46-49`。
- **CG-04 · P2 · 详情里一排技术字段与术语** — 模型 / 后端 / 方言 / seed、「字节已清理」（格子上也有）、「钉成正文显示」「把这次的 seed 钉给X」、「这份手改提示词是为另一方言写的」。证据：`CgGalleryDetail.vue:224-225,255-270,332,355`、`CgGalleryPanel.vue:315-317`。方向：技术行收进「技术信息」折叠，措辞换成「图片已清理以节省空间」「设为正文显示的这张」。
- **CG-05 · P2 · 空态会让人误以为图会自己出现** — 「画卷尚空 —— 故事里出现值得配图的时刻，画好的插画会收在这里」，而默认是手动档，不点按钮、不配好图像连接就永远是空的。证据：`CgGalleryPanel.vue:358`、`settings-store.ts:367`。
- **CG-06 · P2 · 窄屏崩版** — 详情固定 22rem 与网格并排。证据：`CgGalleryDetail.vue:363-365`、`CgGalleryPanel.vue:384-388`。
- **CG-07 · P3 · 标题/说明只能靠双击进入编辑**，唯一的线索是悬停提示「双击可改」。证据：`CgGalleryDetail.vue:187-216`。

### 6.9 快照

- **SNP-01 · P1 · 恢复是不可逆的，但恢复之前分不清哪个快照是哪个** — 每行只有「第N回合」、原因标签、角色名与 HP、游戏日期、现实时间；没有玩家当时的输入，也没有正文摘录。想「回到攻击守卫之前」只能猜回合数，而确认框写明之后的进度全部丢弃。证据：`SnapshotPanel.vue:127-141`、`types.ts:1559-1566`。方向：在预览里存并显示那一回合的玩家输入与正文首句，或把每行链到对应消息。 📌 2026-11-14 已修（PR #151，未真机）：每行显示那一回合的玩家输入与正文首句（`snapshot-turn-context.ts`，取自已载入消息，不读快照体）。

- **SNP-03 · P2 · 读取失败显示成「暂无快照（对话几轮后会自动产生）」**。证据：`SnapshotPanel.vue:40-47,155`。 📌 2026-11-14 已修（PR #151，未真机）。
- **SNP-04 · P3 · 生成进行中「恢复到此」仍可点，读完并接受确认框之后才被拒绝**；图鉴、快照、新模式记忆在数据还在读取时就显示空态文案。证据：`SnapshotPanel.vue:104,143-149`、`CgGalleryPanel.vue:131-133`、`StoryMemoryV2Panel.vue:58,213`。 📌 2026-11-14 部分已修（PR #151，未真机）：生成中「恢复到此」禁用并写明原因；快照面板有读取中 / 失败态。图鉴与新模式记忆的空态未改。

### 6.10 调试

- **DBG-01 · P3 · 调试面的毛边** — 「导出 JSON / 复制到剪贴板」没有反馈；有两个名字不同的调试面（弹窗「调试 & 导出」与 `Alt+Shift+D` 的英文「Debug Panel」抽屉）；「下回合触发」会改游戏状态却不确认。证据：`DebugPanel.vue:335-361,376-377,479-490`、`GamePage.vue:568-594`。

### 7.2 布局

- **GAME-01 · P1 · 窗口窄于 900px 时游戏页不可用：菜单按钮与右栏被裁掉，且无法滚动** 🖥 ✔ — 页面被钉成最小 900px 宽，而 body/#app 是 `overflow: hidden`。实测 768px 宽时「菜单」按钮位于 x=823~888（屏幕外），横向滚不动；375px 时正文、输入框、发送键、状态栏全部在屏幕外，只剩工具栏与场景栏。桌面半屏窗口还能靠 Esc 开菜单，触屏设备没有 Esc，也没有右键（回退/配图/润色全部做不了）。顶栏那条 720px 媒体查询因为 900px 下限成了死代码。证据：`GamePage.vue:613-615`、`base.css:22-28`、`TopBar.vue:128`。方向：做窄屏版式 —— 正文全宽，场景与状态改成抽屉/页签，菜单常驻可见。 📌 2026-11-14 不处理：主人裁定「暂不做移动端适配，只考虑 PC / 笔记本显示器比例」。
- **GAME-02 · P2 · 1024 宽时正文只占不到一半，两侧栏都收不起来** 🖥 — 实测工具栏 + 场景栏 + 状态栏占掉约 54% 宽度，正文列约 470px；「折叠侧栏」只是把工具栏的文字标签藏掉（4.2rem → 1.9rem），省出来的空间还被场景栏吃掉。场景栏与状态栏都没有折叠，折叠状态刷新后也不记。与「叙事优先」相悖。证据：`SideToolbar.vue:55-63`、`GamePage.vue:620-631`、`ScenePanel.vue:466-468`、`StatusHUD.vue:16-18`、`game-store.ts:708`。方向：两侧栏可收起并记住选择，提供专注阅读模式。
- **GAME-03 · P3 · 右栏在 1024×768 下很挤** 🖥 — 没有画像时一个约 170px 高的首字占位块排在最上面，「持有物」被挤到折叠线以下，标题折成「持有 / 物」两行、「1250 G」也断行，装备页签贴底只露出半行。方向：没有画像时把占位块缩成一行头像。

### 7.3 回合操作

- **GAME-04 · P1 · 回退、重来、配图、润色只存在于右键菜单里** — 想重掷一个不满意的回合，界面上找不到任何按钮；唯一的线索是消息上的原生悬停提示，以及「菜单 → 帮助说明」里的一行。而且「重新生成」要两步：回退本轮把输入填回去，玩家还得自己再按回车。没有重新生成、编辑输入之类的可见入口。证据：`ChatFlow.vue:283-290,450-453,476-481`、`GameMenu.vue:95`。方向：在最新一回合上放可见的操作条（重新生成 / 编辑输入 / 回退），右键保留为快捷方式。 📌 2026-11-14 已修（PR #151，未真机）：最新一回合下方加可见操作条（重新生成 / 回退 / 润色 / 配图 / 复制），右键保留；「重新生成」确认后回退并用同一句输入重发。「编辑输入」未做。
- **GAME-05 · P1 · Agent 模式下回合失败从不说原因** — 密钥错误、重试后仍 429、网络错误，玩家看到的都只是「世界的回应在此中断，已写入的状态不会自动撤销；可回退后再次尝试。」真正的错误只进控制台（直出模式会 toast，Agent 模式不会），各步骤的错误信息被丢弃。再试几次也只会再失败。证据：`game-pipeline.ts:1183-1189`、`game-store.ts:641-649`、`TurnActivityLedger.vue:218-221`。方向：在失败的回合进程上显示归类后的原因（密钥 / 额度 / 限流 / 网络 / 内容）并给「去设置」。 📌 2026-11-14 已修（PR #151，未真机）：失败归类为密钥 / 额度 / 限流 / 网络 / 服务端 / 拒绝 / 配置 / 未知并给出下一步（`lib/turn-failure.ts`），原文脱敏截断后收进技术详情，附「去设置」。
- **GAME-06 · P1 · 「回退本轮」直接销毁一个花钱生成的回合，不确认也不能撤销** ✔ — 它与「复制」「润色正文」挨在一起，点错即刻恢复到上一个快照，最新一回合与之后的手动改动全部丢弃。证据：`ChatFlow.vue:296-306,589-597`、`game-store.ts:1520-1546`。方向：确认框，或带「撤销」的 toast。 📌 2026-11-14 已修（PR #151，未真机）：回退前确认。
- **GAME-07 · P1 · 「润色正文」不可逆地覆盖原文，没有确认，也不防重入** — 润色结果就地替换消息内容，5 秒内自动存档把它并进本回合快照，原文就此消失（唯一的「撤销」是回退整个回合）。这次调用不置「生成中」，所以可以连点两次（两次付费），也可以在它跑的时候发下一回合；也没有停止按钮。证据：`ChatFlow.vue:330-346`、`game-store.ts:1616-1642`、`useAutosave.ts:32-36`、`game-pipeline.ts:1380-1386,4566-4568`。方向：保留原文为可还原版本（或给预览 + 接受/放弃），禁止重入，运行时锁输入。 📌 2026-11-14 已修（PR #151，未真机）：保留第一次润色前的原文（`ChatMessage.preRewriteContent`），可「还原润色前」；润色中不能再点、不能发送新回合。**停止按钮仍没有**。
- **GAME-08 · P1 · 生成进行中离开游戏页，会悄悄中止这个付费回合与在飞的插画** — 游戏菜单的「设置」「扩展」「返回首页」、插画格的「去设置」都会导航离开，游戏页卸载时中止管线与全部插画请求；生成中没有任何警告，被中止的插画照样计费。与 G-03、G-16 同源。证据：`GameMenu.vue:67-87`、`SceneImageSegment.vue:452-454`、`ui-store.ts:77-95`、`GamePage.vue:352-380`。方向：生成中先确认；更根本的是让设置以不卸载游戏页的浮层方式打开。 📌 2026-11-14 已修（PR #151，未真机）：离开游戏页的各入口先过确认（`lib/leave-game-guard.ts`）。设置浮层化未做。
- **GAME-09 · P1 · 失败状态与「再次尝试」按钮在任何一次重挂后消失** — 回合失败后去一趟设置页（或刷新、切换存档）再回来，内存里的回合进程记录已被清空：只看到自己的输入，下面什么都没有，没有失败标记也没有重试按钮；唯一的出路是藏在右键里的「回退到这条输入」。证据：`game-store.ts:582,1263-1265,1363-1385`、`ChatFlow.vue:464-471`。方向：从已持久化的回合状态推导失败横幅与重试。 📌 2026-11-14 已修（PR #151，未真机）：从持久化的 `storyTurnStatus` 推导「上一回合未完成」横幅与重试（`lib/turn-recovery.ts` + `TurnRecoveryPanel.vue`）。
- **GAME-10 · P1 · 重试之后，失败的那次尝试仍像正常正文一样留在页面上** — 旧的输出只被标记为失败但不从列表移除，渲染时不区分；于是同一条输入下面出现两段连续的叙事，没有任何「已废弃」标识。证据：`game-pipeline.ts:887-896`、`ChatFlow.vue:476-500`。方向：隐藏或折叠成「已废弃的尝试」。 📌 2026-11-14 已修（PR #151，未真机）：折成一行「已废弃的尝试（N）」。
- **GAME-11 · P1 · 输入法选字时按回车会直接发送** ✔ — 回车处理不检查 `isComposing`。在回车提交候选时 keydown 仍报 `Enter` 的环境（macOS 上的 Chrome/Safari、部分 Linux 输入法）里，确认一个拼音候选就把半句话发了出去，开始一个付费回合。Windows 上的 Chrome 报的是 `Process`，不受影响。证据：`InputBar.vue:43-49`。方向：`e.isComposing || e.keyCode === 229` 时忽略回车。 📌 2026-11-14 已修（PR #151，未真机）。
- **GAME-12 · P2 · 打好的字会在几条路径上丢失** — 输入框在管线接纳这次运行之前就清空了，若准入被拒（只有 toast）或存档正忙（完全静默），文字就没了；草稿与回退填回的输入都是组件本地状态，去一趟设置页回来就丢。证据：`InputBar.vue:56-62`、`GamePage.vue:382-386`、`game-pipeline.ts:584-589,622-630,827-830`。方向：接纳之后再清空；草稿按存档持久化。
- **GAME-13 · P2 · 回合生成期间不能预先打下一步的字** — 整个生成过程（Agent 模式常常几分钟）输入框都是禁用的。证据：`InputBar.vue:103`、`ChatFlow.vue:576`。方向：只禁发送，不禁输入。
- **GAME-14 · P2 · AI 给的行动选项藏在一个没有解释的小图标后面，帮助里描述的界面并不存在** 🖥 — 选项只表现为输入栏左边一个纯图标按钮，没有数量也没有「有新选项」的提示；帮助说明写「点击轮次上的选项 —— 把待选行动填进输入框」，但正文里从不渲染选项。选项浮层按 Esc 或点外面也关不掉（Esc 会在它上面打开游戏菜单）。证据：`InputBar.vue:71-95`、`ChatFlow.vue:43`、`GameMenu.vue:101`、`GamePage.vue:317-323`。方向：把选项做成输入框上方的一排按钮，修正帮助。
- **GAME-15 · P2 · 开场那一回合不能重来，菜单却给了「回退本轮」再拒绝** — 第 1 回合上点它只会 toast「已是最早回合，无可回退」；不喜欢的开场除非生成失败，否则没法重掷。证据：`ChatFlow.vue:246-262`、`game-store.ts:1533-1534`。 📌 2026-11-14 已修（PR #151，未真机）：开场回合不再给回退 / 重新生成入口，并写明原因。
- **GAME-16 · P2 · 「再次尝试」与它旁边的说明自相矛盾** — 说明写「已写入的状态不会自动撤销；可回退后再次尝试」，紧挨着的按钮却是不回退直接重试；玩家分不清哪个安全。证据：`game-pipeline.ts:1166-1168,1188`、`TurnActivityLedger.vue:218-221`、`GamePage.vue:388-394`。方向：给明确的「回退并重试」，或说清重试会保留什么。 📌 2026-11-14 已修（PR #151，未真机）：两条出路「再次尝试」（不回退）与「回退并重试」并列，各自写明会保留什么。
- **GAME-17 · P2 · 侧链调用被标成回合的结果** — 润色正文会在最新输入下面多出第二张「回合进程」卡，随后显示「本回合完成」，润色失败时显示「本回合未完成」—— 而那个回合其实是成功的。证据：`game-pipeline.ts:4566-4568`、`game-store.ts:597-611,651-652`、`TurnActivityLedger.vue:30-43`。 📌 2026-11-14 已修（PR #151，未真机）：润色的活动卡用它自己的名字，不再标成回合结果。

## 八、贯穿全应用的几类问题

把上面两百来条归一下类，主人说的「藏得深、找不到、不直观」主要来自这七个根子。按根子修比逐条修划算。

1. **首次上手没有一条明路。** 新玩家要做三件事（导入内容包、加一个 API、建角色），界面上没有任何地方把这三件事串起来：内容包埋在数据分区底部（S-01），加 API 没有预设（S-11），加完后 16 个红叉让人以为还要逐个配置（S-08），而真正失效的那一个反而是绿勾（S-00）。建议做一个首次启动引导，或至少在首页给一个「开始前的三步」清单。
2. **关键操作只藏在右键、悬停、双击里。** 回退与重来（GAME-04）、心声（GAME-25）、时间线全文（PLT-03）、图鉴改标题（CG-07）、存档行操作（G-13）。触屏与键盘用户完全碰不到。
3. **同一件事有两个互不相通的地方。** 两套 NPC 详情（CHR-01/03）、快照与存档管理（GAME-19）、两个自定义背景（C-24）、三个剧透开关（PLT-02）、两套记忆界面（MEM-03）、两个调试面（DBG-01）、背包里「装备」既是页签又是筛选项（ITM-06）。
4. **离开游戏页就会卸载它。** 设置、扩展都是整页导航，于是进行中的回合被中止（GAME-08、G-03、G-16）、输入草稿丢失（GAME-12）、失败状态丢失（GAME-09）。把设置做成不卸载游戏页的浮层，这一串问题会一起消失。
5. **破坏性与花钱的操作确认不一致。** 有的用原生框，有的用应用内弹窗，有的点两次，有的完全不问（G-07）。一键生效且不可逆的至少有：回退本轮、润色正文、设为当前位置、删除 API、删除预设、删除美化规则、卸载内容包、Story 新模式开关、加载角色预设、图鉴重画。
6. **面板状态不留存。** 弹窗关闭即卸载（G-10），设置页切分区不复位也不记忆（G-01、G-02），表单弹窗一碰遮罩就丢稿（G-11）。
7. **把实现细节直接讲给玩家听。** 内部 id（C-02、MEM-01）、Agent 名与开发术语（S-42、MAP-11、CG-04、PLT-05）、设计动机式的长说明（S-06）、调试功能外露（C-18）。

另外两条横向的：**窄屏基本没做**（GAME-01、G-12、S-29、S-44、C-28、CHR-06、ITM-04、CG-06、MAP-10），以及**键盘可达性有系统性缺口**（一批可点击的 div：C-19、C-26、CHR-02、QST-05、MAP-09）。
