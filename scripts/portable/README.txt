叙事引擎 · Windows 便携版 {{VERSION}}（测试版）
==================================================

这是什么
--------
这是游戏的 Windows 免安装版本。压缩包里自带运行环境和游戏文件，
解压后双击即可在本机启动，游戏界面在你的浏览器里打开。

运行要求
--------
- Windows 10 或 Windows 11，64 位（x64）。
- 不需要另外安装 Node.js 或其他软件。
- 需要你自己的大模型 API Key：进入游戏后在「设置」里填写。

使用步骤
--------
1. 先把整个压缩包完整解压到一个文件夹。
   不要在压缩软件的预览窗口里直接双击运行，那样会缺文件。
2. 双击解压出来的 Start.bat。
   浏览器会自动打开游戏页面：{{URL}}
3. 游玩期间请保持那个黑色命令行窗口开着（可以最小化）。
   关闭这个窗口 = 退出游戏服务。

注意事项
--------
- 不要在黑色窗口里用鼠标点击或框选文字。
  Windows 的「快速编辑」模式会让服务暂停，游戏就像卡住了一样。
  如果不小心点了，按 Enter 或 Esc 即可恢复。
- 首次运行时如果弹出 Windows SmartScreen 蓝色提示，
  点「更多信息」→「仍要运行」。

存档在哪里
----------
游戏地址固定是 {{URL}}。
存档保存在你所用浏览器里、这个地址名下。因此：
- 换浏览器、或清除浏览器数据之前，请先用游戏内的「导出备份」
  功能把存档导出保存，之后再导入。
- 不要改用别的地址（例如 localhost）打开，否则看不到原来的存档。

如何升级
--------
1. 先关闭旧版本正在运行的黑色命令行窗口（如果开着的话）。
2. 把新版本的压缩包解压到任意文件夹，运行新的 Start.bat。
因为游戏地址不变，原来的存档会自动保留。旧版本文件夹可以删除。
如果忘了关旧窗口，新的 Start.bat 会提示「已有另一个版本正在运行」，
按提示关闭旧窗口后再运行一次新的 Start.bat 即可。

端口被占用怎么办
----------------
游戏固定使用本机的 15173 端口。
- 如果同一版本的游戏已经在运行，再次双击 Start.bat 只会重新打开浏览器页面。
- 如果提示另一个版本正在运行，请先关闭那个版本的黑色窗口再试。
- 如果窗口提示端口被其他程序占用，请关闭那个程序，或重启电脑后再试。

内容包
------
游戏内容包需要在游戏内通过 Discord 登录后获取。

隐私说明
--------
你的 API Key 只保存在你自己的浏览器里。
调用模型的请求只经过你本机上运行的这个本地服务，
直接转发给你在设置里配置的模型服务商。
